# 설문 집계기 계획서

## 목표
엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를 보여 주는 단일 페이지 `index.html`.

## 제약
- 배포물은 `index.html` 한 파일. 외부 라이브러리·외부 글꼴·분석 도구 없음.
- 붙여넣은 데이터는 브라우저 밖으로 보내지 않고 어디에도 저장하지 않는다.
  - 네트워크·저장 API(`fetch`, `XMLHttpRequest`, `localStorage`, `sessionStorage`, `indexedDB`, `document.cookie` 등)를 쓰지 않는다.
  - CSP 메타 태그(`default-src 'none'`)로 외부 요청 자체를 막는다.
- 저장소 맨 위에 빈 `.nojekyll` 파일(GitHub Pages가 Jekyll 처리를 건너뛰게).

## 집계 규칙
1. 입력은 탭으로 구분된 텍스트(엑셀 복사 형식). 줄바꿈은 `\r\n`, `\n`, `\r` 모두 인정.
   엑셀이 따옴표로 감싼 칸(칸 안에 줄바꿈·탭이 있을 때)도 한 칸으로 읽는다.
2. 첫 줄은 머리글. 첫 열(응답번호)은 집계하지 않으며, 둘째 열부터가 문항이다.
3. 칸 판정 (앞뒤 공백을 지운 값 기준)
   - `1`·`2`·`3`·`4`·`5` 중 하나 → 유효
   - 비었거나 공백만 → 빈 응답
   - 그 밖의 값(`0`, `6`, `3.5`, `１`, `무응답` 등) → 제외
4. 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 센다.
5. 평균 = 유효 응답의 합 ÷ 유효 응답 수, 소수 셋째 자리에서 반올림해 둘째 자리까지(예: `3.00`).
   유효가 0이면 `-`. 부동소수 오차를 피하려고 정수 연산으로 반올림한다.

### 명세에 없는 경우의 처리(결정 사항)
- 입력 끝의 완전히 빈 줄(엑셀 복사 시 붙는 마지막 줄바꿈 등)은 응답 줄로 치지 않는다.
  중간에 있는 빈 줄은 규칙 4에 따라 모든 문항이 빈 응답인 줄로 센다.
- 칸 수가 머리글보다 많은 줄의 남는 칸은 무시한다.
- 머리글에 문항이 없거나(열 1개) 입력이 비면 표 대신 안내 문구를 보여 준다.

## 구조
- `index.html`
  - `<script id="tally-core">`: 계산 로직. DOM·전역 상태를 건드리지 않는 순수 함수
    (`parseTSV`, `classifyCell`, `formatAverage`, `tally`). 브라우저에서는 `SurveyTally` 전역, Node에서는 `module.exports`.
  - 화면 스크립트: 입력창·버튼·결과 표. 값은 `textContent`로만 넣는다.
- `tests/`: Node 내장 시험 도구(`node --test`)로 실행, 의존성 없음.
  - `core.test.js`: `index.html`에서 `tally-core` 스크립트를 꺼내 `vm`으로 실행해 로직 시험.
  - `static.test.js`: 외부 자원·네트워크·저장 API를 쓰지 않는지, `.nojekyll`이 빈 파일인지 검사.
- `.github/workflows/test.yml`: 푸시·PR마다 `node --test` 실행.

3. 화면
4. 정적 검사 시험, CI, README
5. 시험 통과 확인 후 PR
